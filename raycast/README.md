# Stashlist for Raycast

Search what you saved in Stashlist, and stash a link, from Raycast.

- **Search Stashes**: type to search by words or by meaning; Enter opens the link, another action opens the stash in Stashlist or copies the link.
- **Stash Link**: saves the link you type, or the one on the clipboard.

Set the address of your Stashlist and an API token (Settings, API tokens in Stashlist) in the extension's preferences.
